질문 원문 기본 제외

한 번의 질문이 답이 되기까지

브라우저에는 AWS 자격증명이 전달되지 않으며, 서버 측 역할과 검증된 계약만 사용합니다.

화면에서 질문 전송

React가 선택한 LOT와 질문을 동일 출처의 FastAPI `/api/chat`으로 보냅니다.

실시간 음성 왕복

브라우저 PCM을 WSS로 전송하고 Transcribe 최종 전사를 같은 Text Agent에 질의한 뒤 Polly PCM 답변을 즉시 재생합니다.

입력과 LOT 일치 검증

FastAPI가 질문 길이, 세션, LOT 형식과 실제 샘플 레코드 존재 여부를 확인합니다.

AgentCore 호출

ECS Task Role이 지정 Runtime Endpoint만 호출하며 JSON 계약과 세션을 전달합니다.

읽기 전용 근거 조회

LOT 계보와 출하 준비 상태를 조회하고 관련 제조 문서를 함께 구성합니다.

Bedrock 답변 생성

Nova 2 Lite가 조회 근거 안에서 한국어 답변을 만들고 출처와 사용 도구를 반환합니다.

안전 경계

  • 설비 제어와 자동 출하 승인 없음
  • 임의 SQL, 셸, 파일 쓰기 도구 없음
  • 운영 ERP, IoT, 고객 개인정보 미연결
  • AgentCore 장애 시 데모 답변으로 자동 전환하지 않음
  • 샘플 기록은 실제 승인 근거로 사용할 수 없음
  • 입력·출력 원본 음성과 서명 URL을 저장하지 않음

배포 자원과 책임

웹 계층과 Agent Runtime을 분리해 변경 범위와 실행 플랫폼을 독립적으로 관리합니다.

CloudFormation 관리 자원

기존 AgentCore 자원은 보존하고 웹 서비스 스택을 별도로 배포했습니다.

복원력

두 가용영역의 private subnet, ALB 헬스 체크, ECS circuit breaker와 자동 롤백을 사용합니다.

비용 경계

Fargate 태스크 1개와 NAT Gateway 1개로 테스트 구성을 제한했습니다. ALB와 NAT는 실행 시간에 따라 비용이 발생합니다.

현재는 CloudFront HTTPS 테스트 환경입니다.

마이크 사용과 WSS는 암호화되며, 운영 전 사용자 인증, WAF, 영속 PostgreSQL을 추가해야 합니다.
