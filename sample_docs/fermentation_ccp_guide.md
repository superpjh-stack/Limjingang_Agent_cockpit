# 발효·CCP·출하판단 운영 예시

> 시제품 검증용 문서이며 실제 HACCP 기준서를 대체하지 않습니다.

## 발효·숙성

- 발효 LOT별 온도, pH, 산도, 염도와 측정시각을 기록한다.
- AI는 품질등급, 완료 예상시간과 이상발효 위험을 제시할 수 있으나 확정 판정은 품질담당자가 수행한다.
- 모델명, 모델버전, 입력 데이터 시점과 예측결과를 감사 가능하게 보관한다.

## CCP

- 혼합·덤퍼와 금속검출 결과를 LOT와 연결한다.
- 주의·부적합 발생 시 관련 LOT를 격리 후보로 표시하고 담당자에게 검토를 요청한다.

## 출하판단

- 발효 상태, CCP 결과, 포장 상태, 고객·수출 기준을 함께 검토한다.
- Agent는 승인 근거를 모으고 누락을 경고하지만 출하를 자동 승인하지 않는다.
