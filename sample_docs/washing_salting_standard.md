# 임진강김치 세척·절임 기준 예시

> 확인된 현장 정보를 반영한 시제품 문서입니다. 실제 승인 기준서의 개정번호와 담당자 승인을 확인한 뒤 운영에 사용해야 합니다.

## 세척·소독

- 기준 작업 예시: 원재료 1,000kg, 용수 3,000L, 세척시간 30분
- 소독수 농도 예시: 10ppm
- 원재료 LOT, 작업시작·종료시각, 용수량, 소독수 농도와 작업자를 기록한다.

## 절임

- 배추 상태와 품종에 따라 절임조건이 달라질 수 있으므로 승인 레시피의 개정번호를 적용한다.
- 절임 LOT별 염도, 온도, 시작·종료시각, 절임조 번호를 저장한다.
- 기준 이탈 시 자동 조건변경하지 않고 품질담당자 검토를 요청한다.
