# 임진강김치 에이전트 V3 — 오늘의 김치연구소

기존 V2 업무 대화·추천질문·자료 조회를 유지하고 연구소를 첫 화면으로 추가했다. 배포 경로와 기존 API는 유지한다.

## 연구 경험

- 김치 탐정소: 명시적으로 선택한 LOT의 연결 계보·공정 측정·CCP·출하 기록을 조회하고, 원인 후보와 누락 자료를 별도로 표시한다. 원인 후보는 조사 가이드이며 자동 원인 진단이 아니다.
- 신제품 아이디어 공방: 고객·섭취 상황·제약을 입력한다. 기본 모드는 3개 기획 템플릿, AI 모드는 서버 모델로 3개 콘셉트와 고객 인터뷰·검증 계획을 생성한다. 제조 가능성은 미검증이다.
- 한 포기의 여행: 실제 조회된 계보로 공정 카드를 만들고 고객용 이야기 초안을 별도로 제시한다. 공개·게시 기능은 없다.
- 60초 김치 라디오: CCP 이탈·재고 부족·출하 검토 건수로 짧은 원고를 만든다. 재생 길이는 음성 속도에 따라 달라진다. 실패한 조회는 0건으로 단정하지 않는다.

현재 DB는 가상·미승인 샘플이다. 연구소 모든 결과와 내보내기에 이를 명시한다. 실제 회사 자료를 연결할 때에는 데이터 출처·기준일 표시도 함께 바꿔야 한다.

## 구현

`POST /api/v3/studio`: mode, lot_id, prompt, audience, occasion, constraint, use_ai.
LangGraph: collect → draft → verify. 응답은 cards, evidence, warnings, speech, pipeline을 포함한다. 근거 ID 유효성과 창작 카드의 근거 오연결을 검사한다. 이는 내용의 정확성이나 제조 안전성 인증이 아니다.

LOT 필수 모드는 detective/journey. 다른 모드는 전달된 LOT를 무시하고 해당 범위의 전체 기록을 조회한다. AI 생성은 기존 서버 인증과 동시 요청 제한을 적용하며 오류 시 조용히 성공 처리하지 않는다. 브리핑 음성은 기존 `/api/voice/speak`를 사용한다.

화면/연구 모드 전환과 LOT 변경은 이전 요청·음성을 취소한다. 업무 대화는 탭 전환에도 유지하며 숨겨지면 음성을 중단한다. 연구 결과의 시작 지점으로 한 번 이동하며 끝으로 자동 이동하지 않는다. 연구노트는 원본 근거와 함께 Markdown 파일로 다운로드하거나 복사할 수 있다.

## 일일생산보고서 자동 생성

대화에서 `2026년 9월 20일 일일생산보고서 만들어줘` 또는 왼쪽 보고서 종류의 일일생산보고서를 선택한다. 날짜 없는 요청은 날짜 선택 UI를 제공하고, 오늘/어제는 한국 시간으로 해석한다. 자료가 없으면 404 안내하며 임의의 다른 날짜를 사용하지 않는다. 범위 요청과 LOT 필터는 현재 지원하지 않으며 명시적으로 안내한다.

`POST /api/reports/daily-production`는 business_date를 받아 DB에서 샘플 실적과 제품을 결합하고 수량 환산을 검증한다. 결과 JSON을 daily_report_exports에 보존한다. `GET /api/reports/{id}/xlsx|pdf`는 같은 스냅샷으로 다운로드한다. 로그인 사용자의 보고서는 소유자를 검사하며, 비로그인 환경의 샘플 보고서는 추측 불가능한 ID로 접근한다. 기존 V2_REQUIRE_LOGIN 정책도 적용된다.

Excel은 v2/templates/daily-production.xlsx 양식에 데이터를 채우며, PDF는 동일 시트의 병합·행열 크기·표 배치를 렌더링한다. 한글 CID 글꼴을 사용한다. 샘플 계획 합계를 사용하며 원본 회사의 인원×270 기준은 이식하지 않는다. 근무·온도·반제품 정보는 미입력으로 남긴다. 포기김치 17행/기타김치 6행을 초과하면 분할 필요를 안내하며 누락된 보고서를 생성하지 않는다.

보고서는 자동 승인·실제 출고·인쇄장치 전송을 하지 않는다. PDF를 내려받아 인쇄한다. 다른 8종 보고서는 요청 예시만 제공하며 자동 파일 생성은 현재 일일생산보고서만 지원한다.

검증: 36 tests passed, 1 skipped; Chrome 데스크톱/모바일에서 대화와 사이드바 생성 및 Excel/PDF 다운로드, PDF 1페이지 한글/표/합계 확인. 운영 서버 배포와 Git push는 별도.
